## 项目详情

### 01. AGV 智能搬运机器人结构设计
* **目录路径**：`./01-agv-robot-design/`
* **项目简介**：面向仓储物流场景，独立承担 AGV 搬运小车底盘与垂直提升机构从 0 到 1 的物理架构设计与力学测算。
* **核心内容**：
  * 基于极限工况的承重与动态力矩校核计算文档。
  * 包含驱动电机、深沟球轴承、直线导轨与齿轮齿条副的 SolidWorks 三维装配体及防干涉检查。
  * 标准件选型清单与非标件加工工程图。

### 02. 郑钦文商业 IP 财务估值建模
* **目录路径**：`./02-sports-ip-valuation/`
* **项目简介**：针对中国网球运动员郑钦文的长期商业潜力，批判性审视传统与 AI 工具预设假设，建立具备可防御性的独立折现现金流（DCF）估值模型。
* **核心量化逻辑**：
  * **参数修正**：引入运动员特定风险溢价（ARP 2.50%）与国别风险溢价（CRP 0.80%），将基准折现率由 12.0% 校正至 18.40%。
  * **终值重构**：剔除盲目套用企业永续增长假说的终值，测算得出 5,813 万美元的稳健商业估值。
* **文件清单**：完整财务测算 Excel 表格、参数敏感性分析报告。

### 03. 开放经济体 DSGE 宏观冲击模拟
* **目录路径**：`./03-macro-dsge-dynare/`
* **项目简介**：基于小型开放经济体（SOE）框架，使用 Matlab 与 Dynare 编写底层逻辑代码，模拟外部产出冲击及风险溢价波动对国内宏观经济变量的动态传导。
* **关键产出**：
  * 底层 `.mod` 模型代码与脉冲响应分析脚本。
  * 外生世界设定与内生新凯恩斯外围经济设定下 8 组核心变量的脉冲响应轨迹（IRFs）对比。
  * 浮动、管理浮动与固定汇率机制的抗冲击性分析报告。

### 04. O2O 平台算法派单与隐形劳动研究
* **目录路径**：`./04-o2o-labor-econometrics/`
* **项目简介**：结合一线实地外卖配送调研与微观计量经济学模型，量化拆解平台调度算法、动态波峰补贴与骑手送餐收入的因果机制。
* **主要产出**：
  * 全英文学术论文（Overleaf / LaTeX 编译）。
  * 调研问卷数据、计量实证回归代码及回归结果表格。
  * 公开学术汇报幻灯片（Presentation Slides）。

## 运行与环境说明

* **宏观模型复现**：需安装 `MATLAB` (R2021a 或更高版本) 及 `Dynare` (4.6+)。在 MATLAB 命令行中运行 `dynare soe_model.mod` 即可输出数值解与 IRF 图像。
* **论文编译**：`04-o2o-labor-econometrics` 目录下的论文使用标准 `TeXLive / XeLaTeX` 编译环境。
* **CAD 查看**：3D 装配模型建议使用 `SolidWorks 2020` 或以上版本打开，仓库内同时提供了轻量级 `.STEP` 格式文件方便跨平台预览。
